# CEPPMailDrafter — Implementation Plan (v1.1)

A Go 1.22+ CLI tool that reads monthly Markdown+custom-tag email templates,
injects YAML data, and outputs RFC 822 / MIME `.eml` draft files for Thunderbird.

> **Decisions locked in (2026-03-30):**
> - Q1 → HTML-only body (`Content-Type: text/html; charset=UTF-8`); `multipart/mixed` only when attachments present
> - Q2 → Attachment support **now** (front matter `attachments:` list, Base64-encoded inline)
> - Q3 → Missing YAML data file → continue with empty data + explicit **error log to stderr**
> - Q4 → `to:`, `cc:`, `bcc:` all support YAML string **or** array of addresses

### 3 — Core types (`internal/writer/writer.go`)

Every other package imports this file; it has **zero internal deps**.

```go
// MailMessage is the fully-rendered email ready for serialisation.
type MailMessage struct {
    From        string
    To          []string   // one or more recipients
    Cc          []string   // optional
    Bcc         []string   // optional
    Subject     string
    Body        string     // HTML content
    Attachments []Attachment
}

// Attachment holds a single file to be embedded in multipart/mixed.
type Attachment struct {
    Filename    string  // display name in email
    ContentType string  // e.g. "application/pdf"
    Data        []byte  // raw file bytes (Base64 encoded by EMLWriter)
}

// Writer is the pluggable output interface.
type Writer interface {
    Write(msg MailMessage, month string) error
}
```

### 5 — `internal/parser` — Two responsibilities

#### 5a. Front matter splitter (`frontmatter.go`)

Splits `---\n...\n---\n` preamble from body.

Returns:
- `frontYAML []byte` — raw YAML for the Renderer to parse into headers
- `body string` — template body (without `---` delimiters)

Errors if:
- No front matter found
- `to` or `subject` missing from front matter keys

Front matter schema (supports string **or** YAML list for address fields):
```yaml
from:    string
to:      string | []string      # required
cc:      string | []string      # optional
bcc:     string | []string      # optional
subject: string                  # required; supports {{VAR}} tags
attachments:                     # optional; list of local file paths
  - ./attachments/report.pdf
  - ./attachments/data.xlsx
```

#### 5b. TagParser (`parser.go`)

Token types:
| Type | Syntax | Notes |
|---|---|---|
| `TokenText` | literal string | passthrough |
| `TokenVar` | `{{KEY}}` | simple substitution |
| `TokenLoop` | `{{#KEY}}…{{/KEY}}` | body repeated per list item; `{{ITEM}}` is the loop variable |
| `TokenCond` | `{{#IF_KEY}}…{{/IF_KEY}}` | rendered if DataSource has truthy key |

Validation:
- Unclosed `{{#TAG}}` → `ErrUnclosedTag`
- Nested block tags → `ErrNestedNotSupported`

### 6 — `internal/data` — DataSource

**Interface:**
```go
type DataSource interface {
    Get(key string) (string, bool)
    GetList(key string) ([]string, bool)
}
```

**YAMLSource:**
- Parses `data/YYYY-MM.yaml` with `gopkg.in/yaml.v3`
- All top-level keys normalised to `UPPER_CASE` to match `{{KEY}}` convention
- Parse errors include line number (yaml.v3 provides this natively)
- **If file does not exist:** `YAMLSource` returns an `EmptySource` and logs
  `[WARN] data file not found: data/YYYY-MM.yaml — continuing with empty data`
  to stderr. Program does **not** abort.

**Multi-source chaining:**
```go
// ChainedSource merges multiple DataSources; later sources win on key conflict.
func ChainedSource(sources ...DataSource) DataSource
```

### 7 — `internal/renderer` — Renderer

```go
type Renderer struct { /* unexported fields */ }

func New(sources ...data.DataSource) *Renderer

func (r *Renderer) Render(frontYAML []byte, tokens []parser.Token) (writer.MailMessage, error)
```

**Logic:**

1. **Parse front matter YAML** → build headers map; expand `{{VAR}}` in every header value (To, Cc, Bcc, Subject).
2. **Resolve address fields** — each of `to`, `cc`, `bcc` is normalised to `[]string` (handles both YAML string and array).
3. **Load attachments** — for each path in `attachments:`, read file bytes from disk, detect MIME type via `http.DetectContentType`, populate `MailMessage.Attachments`.
4. **Walk token list:**
   - `TokenText` → append as-is
   - `TokenVar` → `source.Get(key)`; if missing → keep original tag text, warn to stderr
   - `TokenLoop` → `source.GetList(key)`; repeat body once per item, substituting `{{ITEM}}`
   - `TokenCond` → render body only if `source.Get(key)` returns truthy (`"true"`, `"1"`, `"yes"`)
5. Return `MailMessage{From, To, Cc, Bcc, Subject, Body, Attachments}`

### 8 — `internal/writer` — EMLWriter & DryRunWriter

#### EMLWriter (`eml_writer.go`)

**MIME structure decisions:**

| Condition | MIME structure |
|---|---|
| No attachments | `Content-Type: text/html; charset=UTF-8` (simple) |
| With attachments | `Content-Type: multipart/mixed` → HTML part + one `application/octet-stream` (or detected) part per attachment |

**Implementation details:**
- Creates `output/` dir via `os.MkdirAll`
- If output file already exists → warn to stderr, then overwrite
- `Subject` → `mime.BEncoding.Encode("UTF-8", subject)` (stdlib `mime` package) → `=?UTF-8?B?...?=`
- `To` / `Cc` / `Bcc` → RFC 5322 comma-joined address list
- `Date` header → `time.Now().Format(time.RFC1123Z)`
- Attachment parts: `Content-Disposition: attachment; filename="..."`, Base64-encoded body
- `X-Unsent: 1` header so Thunderbird recognises the file as a draft

#### DryRunWriter (`dryrun_writer.go`)

- Implements same `Writer` interface
- Prints header block (`From`, `To`, `Cc`, `Bcc`, `Subject`, attachment list) followed by `---` then body to stdout
- Zero filesystem writes

### 9 — `cmd/maildraft/main.go` — CLI entrypoint

**Flags (stdlib `flag`):**
```
--month          string   (required) Target month, e.g. 2025-01
--template-dir   string   (default: ./templates)
--data-dir       string   (default: ./data)
--output-dir     string   (default: ./output)
--dry-run        bool     Use DryRunWriter instead of EMLWriter
```

**Pipeline:**
```
main()
  └─ parse flags → if --month missing: print usage, exit 1
  └─ FileLoader.Load(month)            → raw template string
  └─ parser.SplitFrontMatter()         → frontYAML, bodyText
  └─ parser.Tokenise(bodyText)         → []Token
  └─ YAMLSource.New(month, dataDir)    → DataSource  (empty+warn if file missing)
  └─ Renderer.New(sources...).Render() → MailMessage  (attachments resolved here)
  └─ writer (EML or DryRun).Write(msg, month)
  └─ exit 0 on success; all errors → stderr, exit 1
```
